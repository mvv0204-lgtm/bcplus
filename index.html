Junta varias búsquedas que ya hayas importado sin volver a consultar Internet. BC+ usa los datos de tus archivos .bcplusresult, elimina duplicados por artista + fecha + recinto y te deja sacar un único archivo para trabajar.

1 · ImportaGuarda enero, febrero, artistas concretos, etc. desde 📥 Importar / archivos.
2 · SeleccionaMarca aquí las búsquedas que quieras unir.
3 · ConsolidaBC+ combina los datos y elimina duplicados sin hacer una búsqueda nueva.
4 · ExportaCSV para Excel, HTML autónomo o PDF listo para guardar.
Importa al menos un archivo .bcplusresult para poder consolidar.

Guía rápida

1. Define correo, ubicación, periodo, artista y estilo.

2. Pulsa 🔍 Buscar conciertos y revisa la configuración.

3. Ejecuta BC+; el motor aplica sus reglas homologadas.

4. Guarda manualmente solo lo que te interese. Cada copia conserva sus propios datos y no existe historial automático ni vigilancia automática.

5. Para trasladar datos usa 📤 Exportar / 📥 Importar. Los archivos que confirmes quedan en 📦 Archivos importados y pueden coexistir varios.

6. Para juntar búsquedas ya hechas abre 📚 Consolidar resultados, marca varias, pulsa 🧩 Consolidar y exporta a 📊 Excel/CSV, 📄 HTML o 📕 PDF. No se repite ninguna búsqueda.

7. Desde ⚠️ Alertas guardadas y ⭐ Conciertos guardados puedes pulsar 🔎 Comprobar ahora para cargar sus criterios y repetir la comprobación manual. En ⚙️ Preferencias puedes crear una 🛟 copia de seguridad completa de todos tus datos locales.
